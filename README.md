# Abflug!

Ein Puzzle-Spiel auf einer Karibikinsel: Schick die Flugzeuge in der richtigen Reihenfolge ans Gate, damit alle Touristen in den Urlaub kommen.

**Spielen:** https://olleeperyt.github.io/abflug/

Alles steckt in einer einzigen Datei, `index.html`, ohne Bibliotheken.

- Tests: `node tests/levels.test.mjs`
- Seite für GitHub Pages bauen: `scripts/pages.sh` (schreibt `docs/index.html`)
